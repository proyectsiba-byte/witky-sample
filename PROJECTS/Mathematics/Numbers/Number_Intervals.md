Number Intervals

An interval is a set of real numbers lying between specified endpoints.

Closed Interval

"[a, b]"

Includes both endpoints.

Example:

"[2, 5] = {x ∈ R : 2 ≤ x ≤ 5}"

Open Interval

"(a, b)"

Excludes both endpoints.

Example:

"(2, 5) = {x ∈ R : 2 < x < 5}"

Half-Open Intervals

"[a, b)" includes "a" but excludes "b".

"(a, b]" excludes "a" but includes "b".

Infinite Intervals

Examples:

- "[a, ∞)": all real numbers greater than or equal to "a".
- "(-∞, b]": all real numbers less than or equal to "b".
- "(a, ∞)": all real numbers greater than "a".

Infinity is not a real number and is never included as an endpoint.
