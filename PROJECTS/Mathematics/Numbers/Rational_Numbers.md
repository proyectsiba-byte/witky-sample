Rational Numbers

A rational number is a number that can be expressed as the quotient of two integers, provided the denominator is not zero.

Definition

A number is rational if it can be written as:

"a/b"

Where "a" and "b" are integers and "b ≠ 0".

The set of rational numbers is represented by "Q".

Examples

- "1/2"
- "-3/4"
- "5 = 5/1"
- "0.75 = 3/4"
- "0.333... = 1/3"

Decimal Representations

The decimal representation of a rational number either terminates or repeats a pattern.

Examples:

- "1/4 = 0.25"
- "1/3 = 0.333..."
- "1/7 = 0.142857142857..."

Equivalent Fractions

Different fractions may represent the same rational number.

For example:

"1/2 = 2/4 = 3/6"
