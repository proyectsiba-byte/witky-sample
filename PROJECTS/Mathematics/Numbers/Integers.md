Integers

Integers are whole numbers that include negative numbers, zero, and positive numbers.

Definition

The set of integers is commonly represented by "Z".

"Z = {..., -3, -2, -1, 0, 1, 2, 3, ...}"

Examples

- Negative integers: "-5", "-2"
- Zero: "0"
- Positive integers: "3", "8"

Fractions such as "1/2" are not integers.

Absolute Value

The absolute value of an integer represents its distance from zero.

Examples:

- "|-4| = 4"
- "|3| = 3"
- "|0| = 0"

Basic Properties

Integers are closed under addition, subtraction, and multiplication. This means these operations on integers always produce integers.

Division does not always produce an integer. For example, "1 ÷ 2 = 1/2".
