Power Sets

The power set of a set "A" is the set of all subsets of "A", including the empty set and "A" itself.

It is commonly represented by "P(A)" or "𝒫(A)".

Example

Let:

"A = {a, b}"

Its power set is:

"P(A) = {∅, {a}, {b}, {a, b}}"

The power set contains four elements, each of which is a subset of "A".

Cardinality

If a finite set contains "n" elements, its power set contains "2ⁿ" elements.

"|P(A)| = 2^|A|"

For example, if "|A| = 2", then "|P(A)| = 4".
