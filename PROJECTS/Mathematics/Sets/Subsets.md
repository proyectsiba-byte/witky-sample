Subsets

A set "A" is a subset of a set "B" if every element of "A" is also an element of "B".

The notation is:

"A ⊆ B"

Example

Let:

"A = {1, 2}"

"B = {1, 2, 3}"

Then "A ⊆ B" because every element of "A" belongs to "B".

Proper Subsets

If "A" is a subset of "B" but "A ≠ B", then "A" is a proper subset of "B".

The notation "A ⊊ B" is often used.

Important Properties

- Every set is a subset of itself.
- The empty set is a subset of every set.
- If "A ⊆ B" and "B ⊆ A", then "A = B".
- If "A ⊆ B" and "B ⊆ C", then "A ⊆ C".
