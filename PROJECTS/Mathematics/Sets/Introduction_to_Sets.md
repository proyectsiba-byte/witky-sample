Introduction to Sets

A set is a well-defined collection of distinct objects. The objects in a set are called its elements or members.

Listing Elements

A set can be described by listing its elements.

"A = {1, 2, 3, 4}"

The order of elements does not matter, and repeating an element does not create a new element.

"{1, 2, 3} = {3, 2, 1}"

Set-Builder Notation

A set can also be described by a property that its elements satisfy.

"A = {x ∈ Z : 0 < x < 5}"

This describes the set "{1, 2, 3, 4}".

Membership

- "x ∈ A": x belongs to A.
- "x ∉ A": x does not belong to A.

Equality

Two sets are equal if they contain exactly the same elements.

Empty Set

The empty set contains no elements and is represented by "∅" or "{}".
