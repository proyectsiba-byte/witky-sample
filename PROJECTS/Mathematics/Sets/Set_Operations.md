Set Operations

Set operations create new sets from existing sets.

Let:

"A = {1, 2, 3}"

"B = {3, 4, 5}"

Union

The union contains elements that belong to at least one of the sets.

"A ∪ B = {1, 2, 3, 4, 5}"

Intersection

The intersection contains elements common to both sets.

"A ∩ B = {3}"

Difference

The difference "A \\ B" contains elements in "A" that are not in "B".

"A \\ B = {1, 2}"

Likewise:

"B \\ A = {4, 5}"

Complement

The complement of a set contains elements of a specified universal set that are not in that set.

The universal set must be defined before the complement can be determined.

Disjoint Sets

Two sets are disjoint if they have no elements in common.

"A ∩ B = ∅"
