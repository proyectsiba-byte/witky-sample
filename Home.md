Witky Sample Wiki

Welcome to the Witky Sample Wiki, a small mathematics knowledge base used to test repository discovery, dynamic indexing, and navigation in Witky.

About This Wiki

This repository demonstrates how a wiki can be assembled from ordinary Markdown files arranged in folders. The application should discover these files from the repository rather than relying on a manually maintained article list.

Projects

- "Mathematics" (PROJECTS/Mathematics/Home.md) — introductory material about number systems and set theory.

Repository Guide

- "Wiki Information" (WIKI_INFO.md)
- "Mathematics Project" (PROJECTS/Mathematics/Home.md)

The application's generated directory tree should reflect the repository's actual contents, including new, renamed, and deleted files after a successful refresh.

Scope and Conventions

- Articles are written in Markdown.
- Links use repository-relative paths.
- Mathematical expressions may use LaTeX-style notation.
- The natural-number convention used here is $\mathbb{N}={0,1,2,\ldots}$.
- This is introductory reference material, not a substitute for a full mathematics textbook.
